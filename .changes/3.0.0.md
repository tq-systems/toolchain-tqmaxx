## 3.0.0

### Added

* Add bare-base, bare and bare-devel images for Ubuntu 14.04 for legacy U-Boot support.
* Support specifying IMAGE for make pull and push.
* add container for development with rust

### Changed

* Leaving IMAGE unspecified for make throws an error instead of applying a default.
* Install ARM GCC 14.2.rel1 and 15.2.rel1 in bare-base/Dockerfile.ubuntu-24.04
* base/Dockerfile.ubuntu-2[0,2,4].04: install curl in base
* Allow passing arguments into devel containers
* bare-base/Dockerfile.ubuntu-24.04: do not install ARM GCC before 12.2.rel1

### Fixed

* Fix and extend README.
* Set registry_base_url default to localhost so building and running containers works without setting the variable.
* not all ubuntu 24.04 image flavours were build with 'make all'
* bare-base/ptxdist-base ubuntu-14.04: install and remove each toolchain .deb within the download loop instead of batching with dpkg -i *.deb.
* base: add missing curl package to ubuntu-16.04 and ubuntu-18.04 base images.
* bare-base/Dockerfile.ubuntu-24.04: wrong modification of /etc/apt/sources.list
